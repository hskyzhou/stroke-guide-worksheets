CONTRIBUTING

参与贡献

欢迎帮助修正教材字表、书写顺序和打印问题，也欢迎改进界面、兼容性和代码。

  1. 说明问题写明字帖类型、使用设置、浏览器、实际结果和期望结果。
  2. 提供依据字表或笔顺纠错请注明出版社、版次、印次、年级、册次和页码。
  3. 验证修改检查中文、英文、数字模式，以及桌面、窄屏和 A4 打印预览。
  4. 说明权利代码或材料贡献需注明来源和许可证，并确认有权提交。

请勿提交

真实学生信息、整本教材扫描件、来源不明的字体、商业素材或无权再分发的内容。安全漏洞请不要公开披露细节。
