PRIVACY

隐私与网络请求

字帖在浏览器中生成。本站没有账户和广告，也不会把练习内容发送到项目服务器；访问与页面性能使用 Cloudflare Web Analytics 进行统计。

保存在当前浏览器

  • 输入的练习文字
  • 字帖排版与书写设置
  • 自定义配置名称和配置内容

这些内容保存在 localStorage 中。可通过重置和删除已保存配置清理，也可以清除该网站的浏览器数据。

从本站加载的资源

  • Patrick Hand 英文字体
  • pinyin-pro 拼音库
  • Hanzi Writer Data 汉字笔画库

这些资源随网站提供。页面启动时不依赖 Google Fonts、jsDelivr 或外部笔画数据服务。

Cloudflare Web Analytics

本站使用 Cloudflare Web Analytics 了解访问和页面性能，包括访问次数、页面浏览量、访问页面、来源网站、国家或地区、设备类型、浏览器、操作系统、页面加载时间和 Core Web Vitals。

统计不包含输入的汉字、字母、数字、自定义配置名称或配置内容。本站不使用该功能建立用户账户，也不通过它在不同网站之间跟踪用户。Cloudflare 的统计脚本和数据接收端点可能在访问页面时产生网络请求。

外部链接

主动点击 GitHub、Ko-fi、数据来源或其他外部链接后，浏览器会访问对应网站，这些网站按照各自的隐私政策处理请求。

其他部署版本

第三方部署者如果改变统计、广告、账户或服务端功能，应提供与其实际处理方式一致的隐私说明。本页面只描述 handwriting.hskylab.com 当前版本。
